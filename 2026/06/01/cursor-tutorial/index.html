Cursor 使用教程：从下载到上手

一、Cursor 是什么

Cursor 是一个内置了 AI 助手的代码编辑器。

简单来说，Cursor 长得跟 VS Code 一模一样——有文件列表、代码编辑区、终端、Git 功能等等。唯一不一样的是，Cursor 直接把 AI 功能嵌到了编辑器里，你不用在 ChatGPT 和编辑器之间来回切换。

你可以这样理解：VS Code 的界面 + 一个随时听你指挥的 AI 程序员。

这个 AI 背后用的是 Claude、GPT 这些大模型。你选哪个模型，它就用哪个来帮你写代码、改代码、回答技术问题。

二、下载与安装

步骤 1：去官网下载

打开浏览器，访问 cursor.com，一进首页就能看到一个醒目的 “Download” 按钮，点它。

页面会自动识别你的系统（Windows / macOS / Linux）并下载对应的安装包。如果自动下载不符合你的需求，也可以手动选择其他系统的版本。

步骤 2：安装

  • macOS 用户：下载的是一个 .dmg 文件，双击打开，把 Cursor 图标拖进 Applications 文件夹就可以了
  • Windows 用户：下载的是 .exe 安装包，双击按提示点”下一步”就行
  • Linux 用户：下载的是 .AppImage 或 .deb 包，按自己系统的安装方式来

步骤 3：登录账号

安装完打开 Cursor，它会引导你登录。三种登录方式：

  • GitHub 账号登录
  • Google 账号登录
  • 用邮箱注册

免费版每个月会送一定次数的 AI 调用额度，日常学习和小项目完全够用。

三、界面介绍

第一次打开 Cursor，你会看到一个代码编辑界面。如果你用过 VS Code，会发现它们几乎一样。

整个界面由这几个区域组成：

区域 在哪 干什么用的
侧边栏 左边 显示文件列表、搜索文件、Git 操作等
编辑区 中间 写代码的地方，可以同时打开多个文件
终端 底部 运行命令用的，比如 python、git
AI 聊天面板 右边（可开关） 跟 AI 对话的地方

在顶部工具栏的右上角，有几个 VS Code 没有的按钮——那就是 Cursor 的 AI 功能入口。

四、三种模式详解

Cursor 有 3 种 AI 交互方式。搞懂它们，你就知道怎么用了。

模式一：Chat（聊天模式）

快捷键：Cmd / Ctrl + L

这个模式最像 ChatGPT，区别是它能看到你当前打开的文件。

按下快捷键后，右边会弹出聊天面板，你可以：

  • 问它：”这段代码是什么意思？”（它知道你选中的是哪段）
  • 问它：”这个报错怎么解决？”
  • 问它：”Python 里 map 函数怎么用？”

因为 AI 能看到你的代码上下文，回答比你在搜索引擎上搜要精准得多。

适用场景： 遇到不懂的代码、报错信息、想学某个语法时。

模式二：Cmd+K（编辑模式）

快捷键：Cmd / Ctrl + K

这个模式是让 AI 帮你改代码。

选中一段你想改的代码，按快捷键，会弹出一个输入框。在框里告诉 AI 你想怎么改，比如：

  • “给每一行加上注释”
  • “把这个函数改成用列表推导式”
  • “这里有个 bug，帮我修一下”
  • “把中文提示改成英文”

AI 会生成修改后的代码，并用对比视图（diff）展示改动的地方。你觉得没问题就点 Accept（接受），不满意就点 Reject（拒绝）。

适用场景： 给代码加注释、修 bug、优化代码写法。

模式三：Agent（智能体模式）

快捷键：Cmd / Ctrl + I

这是 Cursor 最强、最常用的模式。 前两种模式只是”聊天”和”改你选中的代码”，但 Agent 模式是直接把一个任务交给 AI 去做。

Agent 可以：

  • 创建文件：让它写一个新文件，它会自动生成
  • 修改文件：告诉它怎么改，它自己动手
  • 删除文件：不需要的代码，它也能清理
  • 执行命令：在终端里自动运行命令，比如装依赖、跑程序
  • 理解整个项目：它会读你的整个项目结构，理解上下文

举个例子：
你在一个空文件夹里，按 Cmd+I，然后输入：

“帮我创建一个 Python 计算器，支持加减乘除，用户输入两个数字就能计算”

Agent 就会自己创建文件、写好代码、可能还会在终端里运行测试一下。你只需要看它做得对不对。

适用场景： 从零写一个新功能、一次完成多个步骤的任务。

六、常用设置

切换模型

在 AI 聊天界面的底部，有一个模型选择下拉菜单，你可以切换不同的 AI 模型。常见的选择有：

  • Claude Opus / Sonnet — AI 编程能力很强，推荐
  • GPT-4o — OpenAI 的模型
  • Cursor 默认 — 让系统自动选最合适的
