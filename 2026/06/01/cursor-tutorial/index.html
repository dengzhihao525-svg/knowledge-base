Cursor 使用教程：从下载到上手

一、Cursor 是什么

Cursor 是一个内置了 AI 助手的代码编辑器。

它基于微软的 VS Code 做了二次开发，所以 VS Code 的基本功能它全都有——文件管理、代码高亮、终端、Git 集成等等。不一样的地方是，Cursor 直接把 AI 聊天、代码补全、自动编程这些功能嵌到了编辑器里。

你可以把它理解为：VS Code 的界面 + 一个随时听你指挥的 AI 程序员。

这个 AI 背后可以对接各种大模型，包括 Claude、GPT、Gemini 等。你选择哪个模型，它就用哪个来帮你写代码、改代码、回答技术问题。

二、下载与安装

步骤 1：去官网下载

打开浏览器，访问 cursor.com，首页上有一个很显眼的 “Download” 按钮。

它会自动识别你的操作系统（macOS / Windows / Linux），直接下载对应版本。你也可以手动选择其他系统的安装包。

步骤 2：安装

  • macOS：下载的是一个 .dmg 文件，双击打开，把 Cursor 拖进 Applications 文件夹就行
  • Windows：下载的是一个 .exe 安装包，双击按提示下一步即可
  • Linux：下载的是 .AppImage 或 .deb 包，按系统方式安装

步骤 3：登录账号

安装完成后打开 Cursor，它会引导你登录。你可以用：

  • GitHub 账号
  • Google 账号
  • 邮箱注册

免费用户每个月有一定额度的 AI 调用次数，日常学习和小项目完全够用。

三、界面介绍

打开 Cursor 后，你会看到这样一个界面。如果你用过 VS Code，会感觉很熟悉。

界面主要分成几个区域：

区域 位置 作用
侧边栏 左侧 文件列表、搜索、Git 等功能的入口
编辑区 中间 写代码的地方，可以同时打开多个文件（标签页）
终端 底部 运行命令的地方，比如 python、git 等
AI 聊天面板 右侧（可打开/关闭） 跟 AI 对话的地方

其中右上角有几个按钮是 VS Code 没有的，那就是 Cursor 的 AI 功能入口。

四、三种模式详解

Cursor 有三种 AI 交互模式，理解它们就能用好 Cursor。

模式一：Chat（聊天模式）

快捷键：Cmd/Ctrl + L

Chat 模式就像在 ChatGPT 里提问一样。你可以：

  • 问它某段代码是什么意思
  • 问它某个报错怎么解决
  • 问它 Python 的某个语法怎么用

它能看到你当前打开的文件，所以回答会结合你的代码上下文，比单独去网页搜索精确得多。

举例：
你写了一段 Python 代码，不理解 map 函数的作用，选中那行代码，按 Cmd+L，在聊天框里问：”这段代码什么意思？”

模式二：Cmd+K（编辑模式）

快捷键：Cmd/Ctrl + K

这个模式是让你让 AI 帮你改代码。选中一段代码，按 Cmd+K，会出现一个输入框，输入你想让它做什么：

  • “给这个函数加上注释”
  • “把这段代码改成用列表推导式”
  • “这个函数有 bug，帮我修一下”
  • “把中文换成英文”

它会生成修改后的代码，并让你预览改动的地方（diff 视图），你可以选择接受或拒绝。

举例：
你写了一个没有注释的函数，选中全部代码，按 Cmd+K，输入”给每行代码加上注释”，它就会自动帮你注释好。

模式三：Agent（智能体模式）

快捷键：Cmd/Ctrl + I

这是 Cursor 最强悍的模式。Agent 跟前面两种模式最大的区别是：它不仅能说话、能改选中代码，还能自己操作整个项目。

Agent 可以：

  • 创建、修改、删除文件
  • 在终端里执行命令（比如装依赖、跑测试）
  • 读取你的整个项目来理解上下文
  • 一次完成多个步骤的任务

举例：
在一个空文件夹里，按 Cmd+I，输入”帮我创建一个 Python 计算器，支持加减乘除，界面要友好的命令行交互”。Agent 就会自己创建文件、写代码，你只需要看看它做得好不好。

六、常用设置

切换模型

在 Chat 或 Agent 界面的底部，有一个模型选择下拉菜单，你可以切换不同的底层大模型：

常见的选项包括：

  • Claude Opus / Sonnet — Anthropic 的模型，编码能力很强
  • GPT-4o / GPT-4 — OpenAI 的模型
  • Cursor 默认（自动选择最合适的）

Cursor Rules（规则设定）

在项目根目录下创建 .cursorrules 文件，可以告诉 Cursor 你的项目规则，比如：

  • “使用 Python 3.12”
  • “代码注释用中文”
  • “遵循 PEP 8 规范”

这样 Cursor 每次生成代码时都会遵守这些规则，不需要每次都重新交代。

这就是 Cursor 的完整上手流程。从下载安装到三种模式的理解，再到动手实操一个功能，你应该已经能开始用了。

把这篇文章中的三种模式记住，平常写代码时多尝试，很快就能习惯 AI 辅助编程的工作方式。
