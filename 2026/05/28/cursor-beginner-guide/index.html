Cursor小白入门指南

什么是 Cursor

Cursor 是基于 VS Code 二次开发的 AI 编程工具，底层对接 Claude 等大模型。跟普通 VS Code + Copilot 插件最大的区别：AI 直接融在编辑器里，不只是补全代码，而是能理解整个项目、执行操作、帮你改文件。

可以把它理解为：一个自带 AI 程序员跟你实时协作的编辑器。

安装

  1. 去 cursor.com 下载对应系统版本（macOS / Windows / Linux）
  2. 安装后首次启动，可以选择导入 VS Code 的配置、插件、快捷键（如果有的话）
  3. 注册 Cursor 账号，免费版有每月用量限制，够学了

三种核心模式

Ask 模式（问答）

快捷键 Ctrl/Cmd + L 打开对话框，问什么答什么。适合：

  • “这段代码是什么意思？”
  • “怎么用 Python 读取 CSV 文件？”
  • “帮我解释一下这个错误”

AI 只回答不直接改代码，适合学习、理解和探索阶段。

Edit 模式（手动编辑）

选中一段代码，Ctrl/Cmd + K 弹出输入框，描述你想要的改动：

  • “把这个函数改成 async 版本”
  • “加一个 try-catch”
  • “给这个变量起个更好的名字”

AI 会生成 diff，你可以预览，确定后再应用。

Agent 模式

这是 Cursor 最强的能力。之前我们聊过 Agent = LLM + 工具 + 循环，Cursor 的 Agent 模式就是这个原理：

  • 能看到整个项目 — 不只是当前文件，还能跨文件理解代码
  • 能执行终端命令 — 安装依赖、运行测试、启动服务
  • 能读写文件 — 新建、修改、删除，全程可控
  • 自动循环 — 一个任务可能需要多个步骤，Agent 自己规划并逐个执行

跟 Claude Code 本质上是同一套逻辑，只是长在编辑器里。

内联补全（Tab）

写代码时 Cursor 会自动预测你接下来要写什么，灰色字提示，按 Tab 接受。这个能力叫 Tab Completion，比传统代码补全强在它能理解上下文——你写了函数名，它知道参数类型；你定义了接口，它知道怎么实现。

精准上下文

Agent 模式最容易踩的坑是给它的上下文太多或太少：

  • 太多 → token 浪费、AI 容易”分心”
  • 太少 → 不够信息做决策

Cursor 的做法是按需索引整个项目（类似 IDE 的符号索引），然后 AI 只读取它需要的部分。你也可以手动 @ 引用文件或文件夹，精准控制上下文范围。

一个实际例子

假设你要用 Cursor 做一个”番茄钟网页”：

  1. Ask 模式：”我想做一个番茄钟网页，需要哪些文件和设计思路？”
  2. AI 给出方案后，切换到 Agent 模式
  3. 说一句：”帮我创建一个番茄钟网页，25 分钟工作 + 5 分钟休息，纯 HTML/CSS/JS”
  4. Agent 会自动创建文件、写代码、甚至帮你打开浏览器预览
  5. 不满意的地方用 Edit 模式 Ctrl+K 改
  6. 写完后再用 Agent 让它”加一个完成音效和通知功能”

整个过程你做的事就是描述需求 + 审阅结果，具体实现 AI 来做。

总结

模式 干什么 快捷键
Ask 问问题，不写代码 Ctrl+L
Edit 改选中代码 Ctrl+K
Tab 内联补全 Tab
Agent 自动完成整个任务 Ctrl+I

对于之前学的 Agent 知识，Cursor Agent 模式就是一个活生生的工程化实例——把它跟你现在用的 Claude Code 对照着看，理解的会更透彻。
