Gateway 和 MCP 的区别

Gateway 和 MCP 的区别

一句话

MCP 是协议标准，Gateway 是运行中的服务。它们不是同一个东西。

角色不同

MCP Gateway
是什么 协议标准 一个运行中的服务进程
负责 定义”工具该怎么描述、该怎么调用” 定义”消息从哪来、到哪去、谁处理”
类比 USB-C 接口规范 路由器

打个比方

在 OpenClaw 中的关系

Gateway 为什么比 MCP 复杂

MCP 只管工具格式。Gateway 还要管：

  • 多渠道适配（飞书、WhatsApp、Telegram 格式都不同）
  • 会话状态管理（谁在跟哪个 agent 聊天）
  • 可靠性和去重
  • 安全和权限控制
