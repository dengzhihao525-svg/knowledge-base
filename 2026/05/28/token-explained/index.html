Token 怎么消耗

一句话

每次调 LLM API，按输入和输出的 token 数量计费。

Token 是什么

Token 是 LLM 处理文本的最小单位。粗略算：1 个中文字 ≈ 1-2 个 token，1 个英文单词 ≈ 1-3 个 token。

省钱技巧

  • 用小模型 — Haiku 比 Opus 便宜几十倍
  • 限制循环轮次 — 设上限防止无限循环烧钱
  • 精简上下文 — 对话历史越短越省钱
  • Prompt Caching — 缓存重复的 system prompt，省 90% input 费
