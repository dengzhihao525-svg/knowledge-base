我对AI的几点思考

从开始学 AI 到现在，有一些想法慢慢清晰了。

不要被名词吓住

刚开始我听 SDK、API、MCP、Gateway、Agent 这些词，感觉每个都很难。但一个个拆开看，其实就是”工具箱”、”通信管道”、”统一接口”、”消息路由”、”自动循环”。每个概念背后都是解决一个具体问题的，没有人一开始就全懂。

Agent 不是魔法

学之前我以为 Agent 是什么高深的东西。但它的核心就是个循环：LLM 思考 → 调工具 → 拿结果 → 再思考 → 回复。Claude Code 是 Agent，Cursor 的 Agent 模式也是 Agent，本质上都是同一套逻辑套了不同的界面。

理解了这个循环，剩下的就是”它能调哪些工具”的问题。

工具比模型更重要

模型本身只能”想”，不能”做”。真正让 AI 有用的，是它背后的工具链条——能读写文件、能搜资料、能调 API、能执行命令。模型是大脑，工具是手。一个聪明的大脑没有手，什么也干不了。

从用 AI 到驾驭 AI

一开始我是”跟 AI 聊天”。慢慢变成”让 AI 帮我做事”。现在在想的是”怎么让 AI 变成一个可以独立运行的系统”。

这个过程有点像：先学会开车，再学会修车，最后自己造车。每个阶段需要的技能不一样，但都在往上走。

记下来比看懂更重要

我建这个知识库的初衷也是这个——听懂一个东西不难，但过两周就忘了。写下来、用自己的话重新组织一遍，这个知识点才真正变成自己的。这也是为什么每篇文章我都尽量用通俗的例子来解释，不是为了别人看，是为了自己以后看的时候还能懂。

还会继续想，继续写。
